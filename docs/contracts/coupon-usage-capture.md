# 제품 서버의 쿠폰 사용 확정

정본은 `contracts/apis/money-api/coupon-usage-capture.schema.json`이다.
로컬·스테이징 내부 연결용이며, 공개 API catalog나 표준 오류 envelope의
승격을 의미하지 않는다. Money 구현과 서버 전용 SDK가 이 계약을 소비한다.

제품은 이용 요청과 Money 예약 참조를 먼저 영속 저장한다. 요청에는 이 두
참조만 보내고, 가격·회원 ID·쿠폰 효과를 보내지 않는다. Core가 검증한
서비스 인증과 Money에 저장된 예약이 권한·금액의 근거다.

확정 영수증의 금액은 64비트 정수 범위의 십진 문자열이다. SDK는 요청한
예약과 영수증의 일치, 원가에서 혜택을 뺀 실제 차감액, 응답 추적 ID를
확인한다. 정상 영수증을 제품 DB에 저장한 뒤 결과를 제공해야 한다.

시간 초과·통신 실패·503·해석할 수 없는 응답은 결과 미확정이다. 같은
이용 요청과 예약으로 다시 확인하며, 새 예약 생성·취소·결과 제공을 자동으로
실행하지 않는다. 결과 제공의 멱등성과 복구는 제품 서버가 소유한다.
