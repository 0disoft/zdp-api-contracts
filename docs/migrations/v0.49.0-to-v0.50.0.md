# 0.49.0에서 0.50.0으로 이전

## 변경 사항

`AuthRegistrationCreateRequest`에 `minimum_age_confirmed`와 `age_policy_ref`가 필수가 됐다. 이전 가입 요청은 두 필드를 보내지 않으므로 새 계약과 호환되지 않는다. 본인 세션의 비공개 선택 프로필 조회·교체 route도 추가했다.

## 소비자 전환

가입 화면은 서버가 제공하는 연령 정책 참조를 사용하고, 이용자가 최소 연령을 확인한 결과를 가입 요청에 전달한다. 클라이언트가 확인 결과를 임의로 참으로 채우지 않는다. Core·BFF·가입 UI를 함께 갱신하고 두 필드가 없는 요청을 거부하는지 확인한 뒤 활성화한다.

선택 프로필은 `docs/account-preferences.md`의 전체 교체·삭제·멱등성 계약을 따른다. 출생연도 자기신고는 연령 검증이나 권한 부여를 대신하지 않는다. 이 문서와 버전 변경은 런타임 배포·활성화 증거가 아니다.
