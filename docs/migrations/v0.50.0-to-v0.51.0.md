# 0.50.0에서 0.51.0으로 이전

## 계약 변경

선택 프로필 저장의 조건부 동의 헤더를 `request_headers`에 구조화했다.
`birth_year`가 null이 아니거나 `interests`가 비어 있지 않으면
`x-zdp-profile-consent: account-optional-profile-v1`을 전달한다. 전체 삭제 요청에는 불필요하다.

## 소비자 변경

OpenAPI의 `x-zdp-required-when.any_nonempty_fields`와 typed fetch operation의
`requestHeaders`를 소비해 조건과 고정값을 전달한다. 동의 여부는 이용자의 명시적 선택을
Core가 재검증하며 SDK가 자동 동의하지 않는다. 조건 변경·필수 헤더 추가는 호환성 검사에서 차단한다.
