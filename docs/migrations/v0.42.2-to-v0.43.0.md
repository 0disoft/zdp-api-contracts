# 0.42.2에서 0.43.0으로 이전

## 변경 사항

합성 두블룬 실험의 `assign_token_upgrade_custody`, `assign_reserve_upgrade_custody` 승인 작업을 제거했다. 이 작업을 생성하거나 승인 요청하는 소비자는 더 이상 유효한 `action_ref`로 보내지 않아야 한다. token과 reserve의 `publish_token`, `publish_reserve`는 각각 게시와 UpgradeCap 소비를 같은 PTB에 넣은 전체 거래를 대상으로 검토·시뮬레이션해야 한다.

## 소비자 전환과 종료 조건

게시 성공만으로 불변화 완료를 주장하지 않는다. package ID, 성공 effects, 해당 UpgradeCap 소비와 생존 cap 부재를 대조한다. 현재 Core 검증기는 PTB를 해독하지 않으며 승인 조회의 `execution_authorized`는 계속 `false`다. 이 변경은 공개 route, 서명·제출 또는 배포 활성화가 아니다. 구버전 작업을 제출하던 내부 소비자를 갱신하고 계약 검증을 마친 뒤에만 새 계약을 사용한다.
