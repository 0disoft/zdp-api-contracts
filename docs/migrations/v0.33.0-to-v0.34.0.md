# 0.33.0에서 0.34.0으로 이전

## 변경 사항

SDK generation input은 `contracts/error-code-catalog.yaml`을 새 원천으로 사용한다. 오류 metadata에 `http_status`, `retryable`, `user_visible`, `localization_key`, `owner_service_id`, `lifecycle_status`가 필수로 추가된다.

## 소비자 조치

SDK 생성기는 먼저 0.34.0 계약을 읽고 중앙 catalog의 여섯 metadata를 생성 모델에 반영해야 한다. 새 SDK 생성과 소비자 검증이 끝난 뒤 0.33.x 입력 지원을 제거한다. route가 참조하는 오류 코드는 catalog 등록, 서비스 소유권, lifecycle 검사를 모두 통과해야 한다.
