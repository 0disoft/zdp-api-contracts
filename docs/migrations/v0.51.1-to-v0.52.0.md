# v0.51.1 → v0.52.0

## 계약 변경

계정 선택 프로필의 관심사 요청·응답 enum에 `personal_finance`, `foreign_languages`, `beauty`, `pets`를 추가했다. 기존 관심사 값은 유지한다. 0.51.1 소비자가 응답을 기존 enum으로만 검사하거나 모든 값을 나열한 분기로 처리하면 새 값을 거부할 수 있어 0.52.0으로 버전을 올렸다.

## 소비자 전환

SDK와 서버·화면의 관심사 enum 및 표시 목록을 함께 갱신한다. 계약을 고정한 소비자는 새 계약 리비전으로 생성물을 갱신하고 새 값 네 개의 조회·저장 처리를 확인한다. 선택 프로필의 조건부 동의 헤더, 전체 교체·삭제, 멱등성 규칙은 유지한다.

이 릴리스는 로그인 알림 정책 Schema와 계약 도구 수정도 포함한다. 실제 제품의 알림 동작이나 관심사 기능 활성화는 각 제품의 배포 절차에서 확인한다.
